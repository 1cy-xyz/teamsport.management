# Staff Management Discord Bot

A complete Discord staff management system built with Python and discord.py.

## Features

### Duty Management

- Start/end shifts
- Track staff hours
- Weekly leaderboard
- Staff profiles


### Sessions

- Create staff sessions
- Attendance panels
- Automatic reminders
- Host management


### Administration

- Create shifts
- Edit shifts
- Delete shifts
- Session management


### Statistics

- Staff statistics
- Active staff tracking
- Lifetime hours


### Logging

Tracks:

- Duty actions
- Admin actions
- Session actions
